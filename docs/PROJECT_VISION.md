# JobFlow — Project Vision

## What is it?

JobFlow is an experimental asynchronous job processing platform.

## Why am I building it?

I want to deepen my backend engineering knowledge by exploring real-world problems found in systems that rely on queues, workers, and asynchronous processing.

## What do I want to learn?

* Queue architecture
* Workers
* Concurrency
* Race conditions
* Locks
* Retries
* Backoff
* Idempotency
* Scheduling
* Dead Letter Queues
* Observability
* Horizontal scaling
* Distributed systems
* Kubernetes

## What is not a priority?

* A highly polished user interface
* A complex Design System
* A large number of product features

## How will I measure my learning?

Each stage of the project should produce:

* An implementation
* An experiment
* Documentation
* Visual evidence
* A reflection on the results
